板子接上 USB，选好型号，点「烧录到板子」。
浏览器会弹出串口选择框——那是系统的授权提示，选中你的板子即可。

烧完会看到什么

板载 LED 走双闪心跳（亮-灭-亮-停），比匀速闪烁更容易一眼认出是刚烧进去的。 同时串口每秒报一次 beat 和运行秒数。

Nano 要选对 bootloader

老款 Nano 跑 57600，新款 optiboot 跑 115200。 选错的表现是「一直同步不上」且没有任何提示——这是新手最常踩的坑。

浏览器要求

Web Serial 需要 Chrome / Edge / Opera，或 Firefox 151+。 Safari 和 iOS 不支持。页面必须是 HTTPS（localhost 除外）。

这只是一半

完整平台里，代码是在服务端编译的；这一页把编译好的固件写死进来， 用来演示「零安装烧录」这一半——它确实不需要任何服务器。

固件由 SketchForge 编译。烧录协议 STK500v1，页面内自带实现，无外部依赖。
